# Smoke Datasets Overview

Quick-start corpora for validating the training stack end to end. Both datasets
are derived from `dataset/dummy_statement.pdf` and share the same synthetic
outputs. A copy of the PDF and the outputs stub live under `train/smoke_dataset`
for convenience.

## 1. `train/smoke_dataset`
- **Grouping:** field-level (`--grouping field`)
- **Records:** two JSON files (`VendorName`, `TotalDue`)
- **Layout:** one JSON per field per page under `samples/`
- **Images:** symlinked via `samples/images/`
- **Source PDF / outputs:** `dummy_statement.pdf`, `outputs.json`
- **Docs:** `train/smoke_dataset/README.md`

Use this when you want to mirror the legacy per-field dataset structure. Ideal
for supervised loss debugging or verifying the dataloader with minimal data.

## 2. `train/smoke_dataset_page`
- **Grouping:** page-level (`--grouping page`)
- **Records:** one JSON bundle with `fields[]`
- **Layout:** each `fields` entry matches the same schema as field-level records
- **Images:** symlinked via `samples/images/`
- **Source PDF / outputs:** reuse assets from `../smoke_dataset/`
- **Docs:** `train/smoke_dataset_page/README.md`

Use this to exercise the new page-grouping flow and confirm that
`ExtractionSampleDataset` flattens bundles correctly.

## Running a smoke train

```bash
python3 -m train.train \
  --config train/config/example.yml  # update root_dir, splits, etc.
```

Set `data.dataset.root_dir` to either `train/smoke_dataset/samples` or
`train/smoke_dataset_page/samples`, adjust splits to avoid empty subsets, and
optionally run in `training.mode: supervised` for a quick loss sanity check.

## Rebuilding from scratch

```bash
python3 -m train.tools.build_dataset \
  --pdf dataset/dummy_statement.pdf \
  --config de_config/dummy_statement.json \
  --outputs tmp/dummy_statement_outputs.json \
  --out-dir train/smoke_dataset \
  --doc-id smoke_doc \
  --grouping field

python3 -m train.tools.build_dataset \
  --pdf dataset/dummy_statement.pdf \
  --config de_config/dummy_statement.json \
  --outputs tmp/dummy_statement_outputs.json \
  --out-dir train/smoke_dataset_page \
  --doc-id smoke_doc \
  --grouping page
```

> Images are shared via symlinks; if you relocate the datasets ensure the
> `samples/images` links still resolve to the PNG directory generated by the
> builder.
